# Claude Code Tools

Tools and skills installed in Claude Code to support the Fiverr freelance business.

## Skills

### UI/UX Pro Max
- **Source:** [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
- **Installed:** `.claude/skills/ui-ux-pro-max/SKILL.md`
- **Trigger:** `/ui-ux-pro-max`

Comprehensive design intelligence for web and mobile UI/UX work:
- 50+ design styles (glassmorphism, brutalism, neumorphism, etc.)
- 161 color palettes by product type
- 57 font pairings with Google Fonts
- 99 UX guidelines (accessibility, animation, forms, navigation)
- 25 chart types for dashboards
- Covers React, Next.js, Vue, Svelte, Tailwind, shadcn/ui, Flutter, SwiftUI

> [!tip] Use this when building landing pages, dashboards, or any visual component for a client project.

## MCP Servers

### Magic by 21st.dev
- **Package:** `@21st-dev/magic@latest`
- **Scope:** user (global)
- **API Key:** configured

AI-powered UI component builder. Lets Claude search, generate, and refine UI components using the 21st.dev component library.

> [!tip] Use for rapid component generation on client deliverables — especially for SaaS, landing pages, and dashboards.
