## Memory Tricks
| Word | Hook |
|---|---|
| **lassitude** | sounds like "last" + "attitude" — you're too tired to have one |
| **precipitate** | think "precipitation" (rain) — something suddenly falling/happening |
| **permeate** | like "permanent" — it spreads and stays everywhere |
| **stringent** | think "string pulled tight" — very strict |
| **surmise** | sounds like "surprise" — you're guessing at something surprising |
| **inveigh** | sounds like "in-vay" — imagine someone ranting in a dramatic way |
| **intrinsic** | think "inside" — it comes from within |
| **interloper** | think "inter-loper" — someone looping into where they don't belong |
| **occult** | think hidden/secret — occulted = hidden from view |
| **millennium** | Y2K, year 2000 — one thousand years |
