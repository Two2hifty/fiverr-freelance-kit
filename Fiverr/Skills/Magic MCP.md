# Magic by 21st.dev

AI-powered UI component builder MCP server.

- **Package:** `@21st-dev/magic@latest`
- **Scope:** user (global across all projects)
- **Installed via:** `claude mcp add magic --scope user`

## What It Does

Lets Claude search, generate, and refine UI components using the 21st.dev component library directly inside a session.

## When to Use

> [!tip] Use for rapid component generation on client deliverables — especially SaaS, landing pages, and dashboards.
