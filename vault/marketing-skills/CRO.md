# Conversion Rate Optimization (CRO) Skills

Six skills cover conversion at different points in the funnel.

---

## Page CRO `/page-cro`

Optimize any marketing page: homepage, landing pages, pricing, feature pages, blog posts.

### CRO analysis framework (in order of impact)

1. **Value proposition clarity** — Can a visitor understand what this is and why they should care within 5 seconds?
2. **Headline effectiveness** — Does it communicate the core value? Is it specific?
3. **CTA placement, copy, and hierarchy** — One clear primary action. Visible without scrolling.
4. **Social proof** — Testimonials, logos, numbers, case studies.
5. **Objection handling** — Does the page address reasons not to buy?
6. **Visual hierarchy** — Does the eye flow to the right elements?
7. **Page speed and technical** — Is it fast and functional?

### CTA copy patterns
- Weak: "Submit," "Sign Up," "Learn More"
- Strong: "Start Free Trial," "Get My Report," "See Pricing"

## Signup Flow CRO `/signup-flow-cro`

Reduce friction in signup, registration, and trial activation flows.

### What it asks
- Flow type (free trial, freemium, paid, waitlist)
- Number of steps and required fields
- Current completion rate
- Where users drop off

### High-impact changes
- Remove fields that are not required at signup
- Use social login (Google, GitHub) to reduce friction
- Show progress indicators on multi-step flows
- Eliminate required credit card for free trials
- Move optional fields to post-signup

### Related
- For post-signup activation: `/onboarding-cro`
- For lead capture forms: `/form-cro`

## Onboarding CRO `/onboarding-cro`

Increase user activation after signup. Get users to their "aha moment" fast.

### Core principles
1. **Time-to-value is everything.** Remove every step between signup and experiencing core value.
2. **One goal per session.** Don't overwhelm new users.
3. **Progress over perfection.** Get users to take one meaningful action.

### What it asks
- What type of product? B2B or B2C?
- What is the "aha moment" (the action that indicates a user gets it)?
- What happens after signup today?
- Where do users drop off in the first session?

### Common patterns
- Interactive onboarding checklist
- Empty states that guide the first action
- Contextual tooltips and in-app prompts
- Progress bars and completion percentages
- Triggered onboarding emails for users who stall

## Form CRO `/form-cro`

Optimize forms that are not signup flows: lead capture, contact, demo request, checkout, surveys.

### What it asks
- Form type (lead capture, contact, demo request, application, checkout)
- Number of fields
- Current completion rate

### High-impact changes
- Remove every field you do not need immediately
- Use inline validation (show errors on blur, not on submit)
- Replace dropdowns with radio buttons when fewer than 5 options
- Add a privacy micro-copy near email fields
- Use a clear, benefit-driven submit button

### Related
- For signup forms: `/signup-flow-cro`
- For popups containing forms: `/popup-cro`

## Popup CRO `/popup-cro`

Design converting popups and modals without damaging brand perception.

### Popup types
- Email/newsletter capture
- Lead magnet delivery
- Discount or promotion
- Announcement
- Exit intent save
- Feature promotion
- Feedback or survey

### Trigger types
- Exit intent: user moves cursor toward browser chrome
- Scroll depth: user scrolled 50% or 70% down
- Time on page: user has been on page 30 to 60 seconds
- Inactivity: user has not moved for 30+ seconds

### What it asks
- Popup purpose
- Current popup performance
- Trigger being used today

### Key principle
A popup that annoys users costs more than it earns. Test frequency caps, delay timing, and targeting rules before scaling.

## Paywall Upgrade CRO `/paywall-upgrade-cro`

Convert free users to paid or upgrade users to higher tiers, at the right moment.

### What it asks
- Upgrade context (freemium to paid, trial to paid, tier upgrade, feature upsell, usage limit)
- What is free vs. behind the paywall
- What triggers upgrade prompts
- Current free-to-paid conversion rate

### Core principle
**Value before ask.** The user should have experienced real value before you ask for payment. Upgrade prompts that appear too early produce resistance. Prompts that appear at the moment of need produce conversions.

### High-converting paywall patterns
- Feature gate: user tries a paid feature, sees an upgrade prompt
- Usage limit: user hits a limit (10 projects, 100 emails sent)
- Trial expiration: user's trial is ending, show what they will lose
- Achievement: user has hit a milestone and is primed to invest more
